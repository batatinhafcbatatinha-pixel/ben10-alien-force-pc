# Controles e Configuração de Vídeo — Ben 10: Alien Force

Inicie o jogo via `jogar-janela.cmd`, `jogar-tela-cheia.cmd` ou `jogar-sem-bordas.cmd`.
O script `run-game.cmd` utiliza a preferência configurada em `video-settings.cfg`.

- **F9:** Janela 1920×1080 (redimensionável).
- **F10:** Alterna para janela sem bordas na resolução da área de trabalho.
- **F11 ou Alt+Enter:** Alterna para tela cheia (1080p).
- **F8:** Exibe/oculta a sobreposição de ajuda de controles.
- **Alt+F4:** Encerra a aplicação.

## Gamepad (Mapeamento Padrão XInput / DirectInput)

| Botão Gamepad (Xbox) | Função PlayStation 2 |
| --- | --- |
| A | X (Pular / Confirmar) |
| B | Círculo (Ataque Especial / Cancelar) |
| X | Quadrado (Ataque Leve) |
| Y | Triângulo (Ataque Forte) |
| D-pad | Direcional D-pad |
| LB / RB | L1 / R1 (Troca de alienígena / Habilidade) |
| LT / RT | L2 / R2 (Bloqueio / Especial) |
| L3 / R3 | L3 / R3 |
| Start | Start (Pausa / Menu) |
| Back / Select | Select |
| Analógico Esquerdo | Movimentação do Personagem |
| Analógico Direito | Controle de Câmera |

## Teclado

| Tecla | Função PS2 |
| --- | --- |
| Enter | Start |
| Tab | Select |
| WASD | Movimentação (Analógico Esquerdo) |
| Setas Direcionais | D-pad |
| IJKL | Controle de Câmera (Analógico Direito) |
| Espaço ou K | X |
| L ou Escape | Círculo |
| J | Quadrado |
| I | Triângulo |
| Q / E | L1 / R1 |
| Shift Esquerdo / Direito | L2 / R2 |
